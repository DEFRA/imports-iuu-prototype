Assumptions and open questions

This page supports user research and describes prototype assumptions. It is not intended to be part of the live service.

Assumptions in this prototype

  • an importer needs one place to track current and previous IUU notifications
  • reference, status, arrival, port, exporter, species and weight are enough to identify a consignment
  • current submissions and previous submissions should be separated
  • users need to understand whether action is required without opening every notification
  • submitted notification data should be read-only
  • users benefit from seeing both document summaries and the values extracted using AI
  • confidence indicators can help users understand why evidence may need further review

Scenarios included

Submitted
A recently submitted notification awaiting review.
Under review
A notification currently being reviewed by a Port Health Authority.
Action required
An NMD has missing authority validation and unclear customs-control evidence.
Previous submissions
Accepted and rejected historical notification examples.

Questions for user research

  • Do importers understand each notification status and what they need to do next?
  • Which information do importers use to identify the correct consignment?
  • Is the dashboard summary sufficient to find and review a previous submission?
  • Is notification information presented in a logical order?
  • Do users understand which values were extracted using AI?
  • Which document information is most valuable?
  • What information is missing from the dashboard or notification overview?
  • What causes confusion, uncertainty or lack of trust?
  • How do users expect to review documents and supporting evidence?
  • Does this dashboard reflect how importers currently manage IUU notifications?

Open design questions

  • Should importers be able to amend a submitted notification, or request an amendment?
  • How should messages and requests from a Port Health Authority appear?
  • Should users see technical AI confidence scores, descriptive labels, or both?
  • How long should previous submissions remain available?
  • Should notifications be grouped by business, agent or importer account?
  • Which document formats should users be able to preview or download?
